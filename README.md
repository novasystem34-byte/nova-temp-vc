# بوت الرومات الصوتية المؤقت(Temp Voice Bot)
[![Donate](https://img.shields.io/badge/Donate-PayPal-00457C?logo=paypal)](https://paypal.me/Alaaabushamaa)
بوت ديسكورد بايثون كامل ينشئ رومات صوتية مؤقتة تلقائياً لكل عضو، مع لوحة تحكم خاصة بصاحب كل روم، وحفظ البيانات في ملفات JSON.

## المميزات
- أمر `/setup` (للإدمن فقط) ينشئ الكاتيجوري وروم "➕ إنشاء روم" تلقائياً.
- عند دخول أي عضو لروم "➕ إنشاء روم"، يُنشأ له روم خاص فوراً ويُنقل إليه، مع صلاحيات صريحة:
  - الروم **ظاهر وقابل للدخول للجميع** (`view_channel=True`, `connect=True`).
  - صاحب الروم يحصل على صلاحيات إدارة كاملة داخل ديسكورد نفسه (تحريك، كتم، تغيير) بالإضافة للوحة التحكم.
- **لوحة تحكم احترافية** داخل شات الروم الصوتي، تتحدث تلقائياً لتعكس الحالة الحية (المالك، القفل/الفتح، الحد الأقصى، عدد المتصلين):
  - قائمة منسدلة ⚙️ تجمع: تغيير الاسم، تحديد العدد، طرد عضو، حظر/رفع حظر، نقل الملكية.
  - 🔒/🔓 زر ذكي واحد للقفل والفتح.
  - 🗑️ حذف الروم يدوياً.
- **نقل ملكية تلقائي**: إذا غادر صاحب الروم ولا يزال هناك أعضاء بداخله، تنتقل الملكية تلقائياً لأول عضو متبقٍ.
- **أخف على السيرفر**: إذا كان العضو يملك رومًا بالفعل، يُنقل إليه بدل إنشاء روم جديد (لا تكرار)، مع قفل داخلي (`asyncio.Lock`) يمنع تضارب الأحداث المتكررة من ديسكورد.
- الروم يُحذف تلقائياً عند خروج آخر عضو منه.
- كل البيانات (`config.json` و `rooms.json`) تُحفظ وتُحمّل تلقائياً، فلا تُفقد الإعدادات عند إعادة تشغيل البوت.

## 1) إنشاء البوت من Discord Developer Portal
1. اذهب إلى: https://discord.com/developers/applications
2. أنشئ تطبيق جديد (New Application) ثم اذهب لتبويب **Bot**.
3. فعّل الخيارات التالية تحت **Privileged Gateway Intents**:
   - `SERVER MEMBERS INTENT`
4. انسخ التوكن (Token) من نفس الصفحة (زر Reset Token إن لزم).
5. من تبويب **OAuth2 > URL Generator**:
   - Scopes: `bot`, `applications.commands`
   - Bot Permissions: `Manage Channels`, `Move Members`, `Send Messages`, `View Channels`, `Connect`
   - افتح الرابط الناتج وادعُ البوت لسيرفرك.

## 2) تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

## 3) ضبط التوكن
انسخ `.env.example` إلى `.env` وضع فيه توكن البوت:
```
DISCORD_TOKEN=توكن_البوت_هنا
```

## 4) تشغيل البوت
```bash
python bot.py
```

## 5) الاستخدام داخل السيرفر
1. نفّذ أمر `/setup` (كإدمن) لإنشاء الكاتيجوري وروم الإنشاء تلقائياً.
   - يمكنك تخصيص أسماء الكاتيجوري والروم عند تنفيذ الأمر (باراميترات اختيارية).
2. أي عضو يدخل روم "➕ إنشاء روم" سيحصل تلقائياً على روم خاص به، مع رسالة ترحيب ولوحة تحكم كاملة في شات الروم.
3. لإلغاء النظام من سيرفر معين، استخدم أمر `/setup-remove` (للإدمن).

## ملاحظات تقنية
- البيانات تُحفظ في `config.json` (إعدادات كل سيرفر) و `rooms.json` (الرومات الحالية وأصحابها).
- لوحة التحكم "Persistent View" أي تعمل حتى بعد إعادة تشغيل البوت.
- التحقق من الصلاحية (أن الضاغط على الزر هو صاحب الروم) يتم في كل زر عبر `rooms.json`.
